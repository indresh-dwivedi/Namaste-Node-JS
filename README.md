## 📖 About This Repository

This repository contains my **code, notes, experiments, and learnings** from
**Namaste Node.js — Season 1 by Akshay Saini**.

The main purpose of this repository is to understand the fundamentals of
**Node.js, JavaScript on the server, Node.js internals, asynchronous programming,
and databases** through practical learning and hands-on coding.
